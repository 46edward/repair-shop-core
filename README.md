# Repair Shop Order Management System

## Tech Stack
- Python 3.13
- SQLAlchemy 2.0
- Pytest
- SQLite

## Quick Start
```
1. Clone the repository and create a virtual environment:
    python3 -m venv venv
    source venv/bin/activate
2. Install dependencies
    pip install -r requirements.txt
3. Run app
    python shop.py
4. Run the test
    python -m test -v
```
